# Movie Rental Web Application

## Project Overview
This project consists of developing a web application for movie rental management. The platform allows users to browse a catalog of movies organized into different categories, providing a structured and intuitive way to explore the available content. Each movie can belong to multiple categories, allowing flexible classification and improved discoverability.

In addition to categories, movies can also be associated with multiple actors. This enables users to easily explore movies featuring specific actors and enhances the overall browsing experience.

The system is designed to support multiple user roles, each with different permissions and responsibilities. Regular users can browse the catalog, rent movies, and manage their active rentals. Staff members can assist with managing the movie database and rental operations. Administrators have full control over the platform, including user management and system configuration.

Users will be able to select a movie, choose the desired rental duration in days, and complete a simulated payment process. Once a rental is active, the platform will allow users to extend the rental period if they wish to keep the movie for a longer time.

The goal of the project is to design a simple but complete web application that demonstrates core concepts of web development, including user roles, relational data management, and interaction between the front-end interface and server-side components.
